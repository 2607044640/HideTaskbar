🥷 HideTaskbar - 极致纯粹的 Windows 任务栏隐藏器
“不要白屏闪烁，不要重启资源管理器，不要修改注册表，我只要任务栏瞬间消失。”

这是一个基于 AutoHotkey v2 编写的轻量级 Windows 任务栏控制脚本。它通过调用底层 Windows API (ShowWindow)，实现了对任务栏的绝对控制。与市面上大多数粗暴修改注册表或频繁重启 explorer.exe 的方案不同，它做到了 0 延迟、0 闪烁、不影响任何原生系统快捷键。

✨ 核心特性（大实话：为什么你需要它？）
🚫 拒绝瞎折腾： 不修改 StuckRects3 注册表，不杀后台。纯原生 Windows API (User32.dll) 直接控制窗口显示状态，丝滑无痕。

⌨️ 完美保留组合键： 采用智能拦截与 A_PriorKey 逻辑，完美兼容 Win + D、Win + 1/2/3 等所有原生快捷键，绝不冲突。

🛡️ 自动突破 UIPI 隔离： 自带管理员提权逻辑。无论你在玩全屏 3A 大作，还是在使用高权限软件（如各类系统工具），快捷键依然 100% 生效，拒绝“间歇性失灵”。

🖱️ Mac Dock 式边缘触发： 鼠标贴近屏幕最底部（2 像素内），任务栏自动浮出；离开即刻消失。

⏱️ 0.2s 绝对守护： 采用高频守护线程，任何流氓软件试图强制唤醒任务栏，都会在 0.2 秒内被重新隐藏。

🎮 操作说明 (Controls)
运行脚本后，你的 Windows 任务栏将默认进入“完全隐身”状态。你可以通过以下方式丝滑操控：

长按 Win 键： 瞬间显示任务栏（此时可配合数字键切换程序）。

松开 Win 键： 任务栏瞬间完全隐藏。

快速双击 Win 键： 呼出 Windows 开始菜单/全局搜索（Pin to Start）。

鼠标触底： 将鼠标移动到屏幕最底端，任务栏自动浮出。

🛠️ 安装与使用
请确保你的电脑已安装最新版的 AutoHotkey v2。

下载本仓库中的 HideTaskbar.ahk 文件。

双击运行 HideTaskbar.ahk。
(注意：首次运行会弹出 UAC 提示，请点击“是”授予管理员权限，以确保脚本能在高权限软件中正常工作。)

💡 进阶修改
如果你想调整触发灵敏度或双击判定时间，可以使用记事本打开 .ahk 文件修改以下参数：

双击速度： 搜索 currentTime - lastWinPress < 300，把 300 改大即可放宽双击的时间限制（单位：毫秒）。

边缘触发高度： 搜索 mouseY >= A_ScreenHeight - 2，把 2 改成 10，即可让底部 10 像素的区域都能触发任务栏显示。
